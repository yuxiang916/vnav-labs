# Lab3 动力学与几何控制

## 旋翼分配矩阵

对理论题图，取屏幕向右为机体 x，向上为 y，出纸面为 z。令 a = d/√2，1–4 号旋翼的平面位置依次为 (−a,+a)、(−a,−a)、(+a,−a)、(+a,+a)。以各旋翼向上的升力 fᵢ 为输入，位置力矩为 (yᵢfᵢ, −xᵢfᵢ, 0)。令 γ = c_d/c_f > 0。气动反扭矩与旋转方向相反。题图 (a) 和 (b) 的矩阵如下，输出顺序为总推力、滚转力矩、俯仰力矩、偏航力矩。

    F_a = [  1   1   1   1 ]    F_b = [  1   1   1   1 ]
          [  a  -a  -a   a ]          [  a  -a  -a   a ]
          [  a   a  -a  -a ]          [  a   a  -a  -a ]
          [ -γ   γ  -γ   γ ]          [ -γ   γ   γ  -γ ]

F_a 的四行互相正交且非零，秩为 4。F_b 的最后一行等于第二行乘以 −γ/a，前三行独立，秩为 3。改装后 τ_z = −(γ/a)τ_x。悬停附近，一个保持水平位置和高度但改变偏航的指令需要非零偏航力矩与零滚转力矩。该组合不可分配，所以不能独立跟踪任意位置与偏航轨迹。

## 阻力补偿

设 R 将机体向量变换到世界坐标系，先计算 v_b = Rᵀv，再逐分量计算 d_b = −diag(0.1, 0.1, 0.2)(v_b ⊙ |v_b|)，最后得到 d_w = R d_b。对世界 z 轴向上的约定，动力学为 m·a = T R e₃ − mg e₃ + d_w。令期望推力向量 A = −k_x(p−p_d) − k_v(v−v_d) + mg e₃ + m a_d − d_w。由 A 的方向计算期望机体 z 轴，由 T = Aᵀ R e₃ 得到总推力。姿态回路随更新后的期望姿态动作。阻力前馈在速度较大时补偿估计到的速度相关扰动。系数误差仍由反馈处理。

## 仿真实现

以 a = c_f d/√2，TESSE 中有独立的旋翼编号与正转约定。由仿真器顶视图和叉乘可得到以下从 sᵢ = ωᵢ|ωᵢ| 到 [T, τ_x, τ_y, τ_z]ᵀ 的映射。

    F = [  c_f  c_f  c_f  c_f ]
        [    a    a   -a   -a ]
        [   -a    a    a   -a ]
        [  c_d -c_d  c_d -c_d ]

控制器用世界系位置和速度误差生成期望推力向量，结合偏航参考构造正交姿态 R_d。姿态误差为 0.5·vee(R_dᵀR − RᵀR_d)。桥接器以世界系给出角速度，计算力矩前用 Rᵀ 转到机体系。偏航角速度由参考消息提供，使用 Rᵀ 把世界系偏航角速度转换到机体系作为前馈。忽略期望倾角的瞬态角速度。单位惯量下陀螺项为零。通过 F⁻¹ 分配有符号平方转速，再换算成 rad/s。阻力补偿是理论题推导，仿真控制器采用课程给定模型。
